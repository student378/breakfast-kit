# 🍱 천원의 아침밥 신청·관리 (대학 배포용)

학생이 휴대폰으로 천원의 아침밥을 신청하고, 담당자가 현장에서 승인·집계하는 웹 프로그램입니다.
구글 스프레드시트와 Apps Script만으로 동작하며, 별도 서버나 비용이 들지 않습니다.

학교마다 다른 값(학교명, 학과, 학번 자리수, 학년, 계좌, 개인정보 보유기간 등)은 **코드를 고치지 않고**
관리자 화면이나 구글 시트에서 입력합니다.

> 처음 설치하는 분은 **[INSTALL.md](INSTALL.md)** 를 순서대로 따라 하세요. (약 30분)

---

## 들어 있는 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 학생 신청 화면 |
| `admin.html` | 관리자 화면 (비밀번호 로그인) |
| `config.js` | **우리 학교 서버 주소 한 줄** — 설치 때 이 파일만 고칩니다 |
| `Code.gs` | 서버 코드 — 구글 스프레드시트의 Apps Script에 붙여 넣습니다 |
| `INSTALL.md` | 설치 안내 |

## 무엇을 할 수 있나

**학생 화면**
- 당일 식단·수량·잔여 확인, 신청 (신청 시간 안에서만, 당일만)
- 학과·학년·학번·성명 입력, 송금 방법 선택(계좌이체/현금), 개인정보 수집·이용 동의
- 계좌이체 선택 시 계좌번호 복사·은행 앱 열기 안내

**관리자 화면** — 실시간 / 운영현황 / 통계 / 요일별 / 학과별 / 학년별 / 시간대 / 서명부 / 점검표 / 학생별 / 목록 / 설정
- 현장 승인(학생 확인 체크), 승인 기준 집계, 서명부·실적 점검표 엑셀 내려받기
- 설정 탭에서 학교 정보·학과 목록·신청 시간·계좌·판매 종료를 바꾸면 학생 화면에 바로 반영

**서버(Code.gs)**
- 학생 화면의 검사를 건너뛴 요청도 서버에서 다시 검사 (학번 자리수, 학과 목록, 학년, 송금 방법, 신청 시간, 당일 여부, 동의 여부, 같은 날 중복)
- 관리자 비밀번호는 스크립트 속성에만 저장(코드·화면 파일에 없음), 10회 연속 실패 시 10분 잠금
- 사업 종료 후 비식별화 도구(성명 삭제, 학번을 일련번호로 대체 — 학과·학년별 통계는 유지)

## 학교별 설정 항목

관리자 화면 **⚙️ 설정** 탭, 또는 스프레드시트 「설정」 시트에서 바꿉니다.

| 항목 | 키 | 예시 |
|---|---|---|
| 학교명 | `schoolName` | ○○대학교 |
| 영문 학교명 | `schoolNameEn` | OO University (비우면 표시 안 함) |
| 운영 부서 | `orgName` | 학생처 학생복지팀 |
| 문의처 | `contact` | 학생복지팀 02-000-0000 |
| 학번 자리수 | `idDigits` | `9` / 여러 개 `8,10` / 범위 `8-10` |
| 학년 선택지 | `grades` | 1학년,2학년,3학년,4학년 |
| 송금 방법 | `payMethods` | 계좌이체,현금지급 (하나만 써도 됨) |
| 개인정보 보유기간 | `privacyRetention` | 학교 개인정보 담당 부서 기준으로 입력 |
| 보유기간 안내 | `privacyNote` | 사업 종료 후 성명·학번은 삭제… |
| 신청 시작·종료 | `startTime` / `endTime` | 08:30 / 10:30 |
| 계좌 | `bank` / `bankNo` / `bankOwner` / `bankAmt` | |
| 비식별화 기간 | `anonFrom` / `anonTo` | 사업 종료 후 사용 |

학과는 「학과목록」 시트 A열(또는 관리자 화면 설정 탭의 학과 목록), 식단은 「식단」 시트(A열 날짜, B열 메뉴, C열 수량)에 입력합니다.

## 미리보기

`config.js` 의 주소를 비워 두면 학생·관리자 화면이 **미리보기 모드**(예시 데이터, 저장 안 됨)로 열립니다.
설치 전에 화면을 먼저 둘러볼 수 있습니다.

## 업데이트 받기

새 버전은 이 저장소의 **Releases** 에 올립니다. 변경 내용을 확인한 뒤
- 화면 파일(`index.html`, `admin.html`)은 새 파일로 교체 — `config.js` 는 그대로 두세요
- 서버 코드가 바뀐 경우 `Code.gs` 를 통째로 교체 → **배포 → 배포 관리 → 연필 → 버전 "새 버전" → 배포** (주소 유지)

신청 기록과 설정은 각 학교의 구글 시트에 있으므로 업데이트해도 그대로 남습니다.

## 개인정보 관련 안내

- 신청 정보는 **설치한 학교의 구글 드라이브(스프레드시트)에만** 저장됩니다. 배포자에게 전송되지 않습니다.
- 개인정보 수집·이용 동의 문구의 **보유기간·처리 주체는 각 학교가 정해야** 합니다. 학교 개인정보 담당 부서와 확인한 뒤 입력하세요.
- 사업 종료 후 비식별화 방법은 INSTALL.md 의 「사업 종료 후」를 참고하세요.
